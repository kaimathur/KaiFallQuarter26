1. What is Git, what is Github, and what is the difference between the two? Git is a version control system that keeps track of your files, and Github is a website built around Git.
2. What is the difference between a local repository and a remote repository? A local repository is stored on a device, and a remote repository is stored externally
3. What does the push command do in Git? The push command uploads the changes from your local repository to your remote repository.
4. What does the commit command do in Git? The commit command saves the file changes in your local repository.
5. What is Github Desktop, & why are we using it?  Github Desktop is an app that lets you use Git and Github easier.
